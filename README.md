# NEXORA ACCESS - Inclusive Digital Workspace
**(Human-Computer Interaction & Accessibility)**

**Student**: Mennakshi S

## 🌟 ABSTRACT
The realm of human-computer interaction & accessibility and modern application development is constantly shifting to accommodate the growing need for robust, secure, and intelligent software solutions. Nexora Access is an inclusive digital workspace designed to provide accessible communication, learning, collaboration, entertainment, career development, and safety support for users with accessibility needs. 

The platform follows a universal design approach, integrating an Accessibility Engine, real-time sign-language recognition, speech-to-text, accessible chat, OCR, personalized learning, and privacy controls.

## 🧩 MODULES
1. **Dashboard (AAC)**: Provides a grid of communication buttons for Augmentative and Alternative Communication (AAC).
2. **Real-time Sign-Language Translation**: Fetches a live simulated stream of OpenCV AI data from the FastAPI backend, updating text dynamically.
3. **Universal Accessibility Engine**: Customize how Nexora looks (Text Size, Color Contrast Themes like Dyslexia Friendly, High Contrast) and sounds.
4. **Accessible Code Lab**: Dyslexia-friendly syntax highlighting where you can type REAL Python code and hit "Run" to execute it securely on the backend!
5. **Gamified Learning & Progress Tracking**: Earn badges and track coding and communication skills (XP is saved persistently in a real SQLite database!).
6. **OCR Book Reader**: Automatically extracts text from images and provides synchronized text-to-speech highlighting for neurodivergent users.
7. **Emergency Assistance Protocol**: A robust SOS dispatch system that logs emergency alerts instantly into the backend database.

## 💻 TECHNOLOGY STACK
- **Front End**: React.js, Vite, Tailwind CSS v4, Lucide React
- **Back End**: Python (FastAPI), SQLite

## 🚀 HOW TO RUN
1. Extract the project folder.
2. Double click the `run.bat` file in the root directory.
3. Two command prompt windows will open automatically.
4. The frontend will launch at `http://localhost:5173`.
5. The backend API will launch at `http://localhost:8000`.
